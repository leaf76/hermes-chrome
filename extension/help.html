Hermes Chrome Guide

Local agent companion for any website — not locked to one product or domain.

You need two parts. The Chrome Web Store package is only the browser half. Agents also need the machine half (local companion: bridge on 127.0.0.1:19876 + Native Messaging host + token). Extension alone cannot control Chrome for agents — if the popup says Setup needed, that is expected until companion install succeeds.
Where to install the companion
  • One-liner (recommended): curl -fsSL https://raw.githubusercontent.com/leaf76/hermes-chrome/main/scripts/install.sh | bash
  • Installs to: ~/.hermes/hermes-chrome (code) + ~/.hermes/run/hermes-chrome (token / logs) · CLI: ~/.local/bin/hermes-chrome
  • Not on npm — there is no npx package.
  • MCP (optional): same install registers Grok / Cursor / Claude Desktop when present. Server file: mcp_server.py under the install root. Snippet: ~/.hermes/run/hermes-chrome/mcp-snippet.json
  • Windows: clone the repo → .\scripts\install-windows.ps1
Works on any page. Open GitHub, docs, dashboards, news — whatever URL you pass. Optional chart helpers exist but are not required.

1. One-time companion install (do this first)

The Chrome extension alone cannot open a control port (Chrome security). Install the companion once per machine before expecting Connected: 

# macOS / Linux (recommended)
curl -fsSL https://raw.githubusercontent.com/leaf76/hermes-chrome/main/scripts/install.sh | bash

# From a clone:
# ./scripts/install.sh
# ./scripts/install.sh --dev   # use this clone in-place

# Windows PowerShell (from a clone):
# powershell -ExecutionPolicy Bypass -File .\scripts\install-windows.ps1

Needs Python 3.9+ and git. Installs bridge + Native Host + optional multi-client MCP.

2. Enable this extension

  1. Reload Hermes Chrome (v1.7+) and accept nativeMessaging if asked.
  2. Click this extension icon once.
  3. Wait for auto-pair, or press Pair in the popup.
  4. Popup should show Bridge online.

3. Use with any page

# Open any URL into the agent workspace
hermes-chrome.sh open 'https://example.com/'
hermes-chrome.sh open 'https://github.com/'

# List / capture
hermes-chrome.sh list-tabs --url example.com
hermes-chrome.sh capture --prefer auto --out /tmp/page.png

# When the task is done — close agent Tab Group only (keep companion)
hermes-chrome.sh stop

# JSON for agents
hermes-chrome.sh --json ping

Closing the workspace does not stop the local bridge. Popup Close workspace does the same when a group is open.

4. Any agent (not only Grok)

Client How
CLI / scripts hermes-chrome.sh --json … or HTTP 127.0.0.1:19876
Grok / Cursor / Claude / … Point MCP at mcp_server.py (same file for all)

Troubleshooting

  • Bridge offline — re-run companion install; click icon; check Python.
  • Native host not found — run install-native-host; reload extension.
  • Need pair — popup Pair, or CLI pair-open then Pair.
  • Tab not found — open URL into Hermes group, or allow cross-workspace in Options.

Full docs on GitHub: docs/GUIDE.md

Hermes Chrome 使用教學

本機 agent companion，適用任何網站——不綁死單一產品或網域。

需要兩半。 商店安裝的只是瀏覽器端。Agent 還需要本機端 companion （bridge 127.0.0.1:19876 + Native Messaging host + token）。 光裝 extension 不夠——popup 顯示 Setup needed 時，代表還沒完成 companion 安裝，這是預期行為。
Companion 從哪裡裝？
  • 建議一行指令： curl -fsSL https://raw.githubusercontent.com/leaf76/hermes-chrome/main/scripts/install.sh | bash
  • 安裝位置： ~/.hermes/hermes-chrome + runtime ~/.hermes/run/hermes-chrome · CLI： hermes-chrome
  • 沒有 npm——不能 npx。
  • MCP（可選）： 同一安裝會註冊 Grok / Cursor / Claude Desktop（若有）。 檔案是 install root 裡的 mcp_server.py，不是 MCP 商店套件。
  • Windows：clone repo 後跑 .\scripts\install-windows.ps1
任何頁面都能用。 GitHub、文件、後台、新聞……你開什麼 URL 就操作什麼。 圖表小工具是可選，不是主線。

1. 一次安裝 companion（先做這步）

光裝 extension 不能開控制 port（Chrome 安全模型）。每台電腦先裝一次 companion，再期待 Connected：

# macOS / Linux（建議）
curl -fsSL https://raw.githubusercontent.com/leaf76/hermes-chrome/main/scripts/install.sh | bash

# 從 clone：
# ./scripts/install.sh

# Windows（在 clone 目錄）：
# powershell -ExecutionPolicy Bypass -File .\scripts\install-windows.ps1

需要 Python 3.9+ 與 git。會裝 bridge + Native Host + 可選多 client MCP。

2. 啟用這個 extension

  1. 重新載入 Hermes Chrome（v1.7+），必要時允許 nativeMessaging。
  2. 點一次 extension icon。
  3. 等 auto-pair，或按 popup 的 Pair。
  4. Popup 應顯示 Bridge online。

3. 操作任意頁面

# 在 agent 工作區開啟任何 URL
hermes-chrome.sh open 'https://example.com/'
hermes-chrome.sh open 'https://github.com/'

# 列表 / 截圖
hermes-chrome.sh list-tabs --url example.com
hermes-chrome.sh capture --prefer auto --out /tmp/page.png

# 任務結束 — 只關 agent Tab Group（保留 companion）
hermes-chrome.sh stop

# 給 agent 的 JSON
hermes-chrome.sh --json ping

關閉工作區不會停本機 bridge。Popup 有工作區時可按 Close workspace。

4. 各種 agent（不限 Grok）

Client 用法
CLI / 腳本 hermes-chrome.sh --json … 或 HTTP 127.0.0.1:19876
Grok / Cursor / Claude / … MCP 指到同一支 mcp_server.py

疑難排解

  • Bridge offline — 重跑 companion；點 icon；檢查 Python。
  • Native host not found — 跑 install-native-host；reload extension。
  • 要 Pair — popup Pair，或 CLI pair-open 再 Pair。
  • 找不到分頁 — 用 open 開進 Hermes group，或 Options 允許跨 workspace。
