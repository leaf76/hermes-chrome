Install the local companion

The store package is only the browser half. The companion lives on GitHub only (not npm / not a store download).

  1. Get it from GitHub

    Companion is not on npm. Source: github.com/leaf76/hermes-chrome. One-liner installs to ~/.hermes/hermes-chrome. Needs Python 3 and git.

    Open GitHub
  2. Run this in Terminal

    From any folder — clones then installs (macOS / Linux):

    curl -fsSL https://raw.githubusercontent.com/leaf76/hermes-chrome/main/scripts/install.sh | bash

    Already cloned? cd into that folder, then ./scripts/hermes-chrome.sh install-for-agent. Windows: open the repo in PowerShell → .\scripts\install-windows.ps1.

  3. Come back here

    Reload this extension, click the icon once, then Pair if asked. Status should say Connected.
